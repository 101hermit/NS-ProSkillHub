## 1. 数据表（29 张 = 核心 11 + 库语义 12 + 专业版 6）

### 1.1 专业版新增（6 张）

| 表 | 行数量级 | 说明 |
| --- | --- | --- |
| `mx_matrix` | 0+ | 实验矩阵（类型 / 维度 / 参数网格 / 用例 / 进度 / 汇总） |
| `mx_cell` | 矩阵数 × 单元数 | 单个单元（输入 / 期望 / 输出 / 推理 / 时延 / 指标分） |
| `kg_entity` | ~639 | 实体：`SKILL/CAPABILITY/SCENE/TAG/AGENT/MCP` |
| `kg_relation` | ~719 | 关系：`BELONGS_TO/IN_SCENE/HAS_TAG/SIMILAR_TO/EVALUATED_BY` |
| `kg_snapshot` | 每次重建 +1 | 图谱快照（规模留痕） |
| `ix_report` | 0+ | 分析报告（方法 / 范围 / 结果 JSON / 中文结论） |

### 1.2 关键字段与约束

| 表.列 | 取值 | 备注 |
| --- | --- | --- |

| `kg_relation` 唯一键 | `(src_code, dst_code, relation_type)` | **重建前必须去重**（踩过坑） |
| `ix_report.method` | `DESCRIBE/HYPOTHESIS/TOPSIS/CLUSTER/REGRESSION/AHP` | |

## 2. 接口清单（专业版新增 13 个端点）

### 2.1 连通矩阵

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/v1/conn/matrix` | `{agents, mcps, cells[], ok_count, total_count, egress}` |
| GET | `/api/v1/conn/heatmap` | 压好的 `{rows, cols, values[][], ok_count, total}` 供 SVG 热力图 |
| GET/POST | `/api/v1/conn/doctor` | 一键体检（出网 + 每格结论），标准版已有 |

### 2.2 实验矩阵

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/v1/eval/matrix` | 创建（body 见下），返回 `{code, planned_cells, ...}` |
| GET | `/api/v1/eval/matrix` | 列表 |
| GET | `/api/v1/eval/matrix/{code}` | 详情 `{matrix, cells[], summary}` |
| POST | `/api/v1/eval/matrix/{code}/run` | 执行全部单元（串行），返回同详情结构 |
| GET | `/api/v1/eval/matrix/{code}/compare` | `{by_skill[], by_agent[], by_params[], conclusion}` |
| DELETE | `/api/v1/eval/matrix/{code}` | 删除（连同单元） |

创建请求体：

```json
{
  "name": "pdf 在三家模型上的表现",
  "matrix_type": "SKILL_SCAN",
  "skill_ids": ["lib:pdf"],
  "agent_codes": ["deepseek-flash", "glm-4-flash", "ark-kimi"],
  "mcp_codes": ["builtin-calc"],
  "param_grid": { "temperature": [0.0, 0.7] },
  "scene_code": "general",
  "cases": [{ "code": "c1", "input": "…", "expected": "…" }]
}
```

### 2.3 知识图谱

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/v1/kg/rebuild` | 重建（清空重建），返回 `{entity_count, relation_count, skill_count, snapshot}` |
| GET | `/api/v1/kg/graph?scene=&limit=` | `{nodes[], edges[], stats}`；`scene` 为空或 `global` 表示全局 |
| GET | `/api/v1/kg/entities?type=&kw=&limit=` | 实体检索 |
| GET | `/api/v1/kg/relations?src=` | 关系检索 |
| GET | `/api/v1/kg/similar/{skillId}?top=` | 相似 Skill（按 `SIMILAR_TO` 权重） |
| GET | `/api/v1/kg/export?format=json\|csv\|graphml&scope=` | 导出（文本） |
| GET | `/api/v1/kg/snapshots` | 快照列表 |

### 2.4 知识级分析

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/v1/ix/analyze` | body `{method, groupBy, matrixCodes[], scope, params}` → 报告 |
| GET | `/api/v1/ix/reports?limit=` | 报告列表 |
| GET | `/api/v1/ix/reports/{code}` | 报告详情 |

> `scope` 既接受字符串也接受对象（例如 `{metric_codes:[...]}`），
> 因为不同调用方对"范围"的理解粒度不同 —— 这是刻意放宽的入参类型。

## 3. 错误码（专业版新增/复用）

| code | HTTP | 触发场景 |
| ---: | ---: | --- |
| 1000 | 400 | 矩阵单元数超 120；`analyze` 请求体不合法 |
| 1300 | 409 | 矩阵还没完成的单元就点"看对比"；只有 1 个可比分组做假设检验 |
| 1100/1101 | 404 | 矩阵 / 报告 / Skill 不存在 |
| 5001 | 500 | 数据库异常（只回第一行原因） |
| 3003 | 502 | 出网被阻断（连通矩阵里会体现为"不通 + 归因"） |

## 4. 数据初始化

```
StartupInitializer.run()
  ①②③ 与标准版相同（建 29 表 / 导入 375 Skill / 同步 6 篇文档）
  ④ MsSeeder（专业版变体）
       · 逻辑库 default / staging
       · 4 个索引、5 条约束、3 个事件
       · 9 条指标字典
       · **4 个 Agent**：local-stub / deepseek-flash / glm-4-flash / ark-kimi
       · 2 个 MCP：builtin-calc（进程内）/ kb-search（内网 HTTP）
```

> 知识图谱**不在启动时重建**（重建要 2.5 s 且会清空用户手改过的关系）——
> 由用户在「知识图谱」页点「重建图谱」显式触发。
